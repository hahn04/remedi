### 콘텐츠 수정과 생성

원본은 한국어 HTML 및 `content/columns/`의 칼럼 원고입니다. `en/`, `zh/`, `ja/` 아래의 HTML은 직접 편집하지 않습니다. 번역 문자열과 문맥은 `content/i18n/catalog.json`, 번역문은 같은 폴더의 `en.json`, `zh.json`, `ja.json`에서 관리합니다. 현재 언어마다 643개 문자열이 있습니다. 원문 기반 ID를 사용하므로 문장이 바뀌면 새 번역이 필요합니다.

1. 한국어 원본을 수정합니다. 칼럼 수정 시 `python -X utf8 scripts/build_columns.py`를 먼저 실행합니다.
2. `python -X utf8 scripts/i18n_catalog.py`로 원문 목록을 갱신하고 세 언어의 새 ID 번역을 채웁니다. 누락이나 템플릿 변수 불일치는 빌드 오류로 알리며 한국어를 대신 게시하지 않습니다.
3. `python -X utf8 scripts/build_site.py`로 칼럼·번역 HTML·도해·사이트맵을 생성하고 검사합니다. `python -X utf8 scripts/build_site.py --check`는 저장된 결과의 재현 여부를 확인합니다.
4. `content/i18n/settings.json`의 `pageModified`에 실제 변경된 페이지 파일명과 날짜를 기록합니다. 예: `"pageModified": {"intro.html": "2026-11-12"}`. 생성기를 실행했다는 이유로 모든 날짜를 바꾸지 않습니다. 한국어 원본의 사이트맵 날짜와 칼럼의 원고 날짜도 실제 수정에 맞게 관리합니다.
5. UTF-8과 화면·동작 확인 후 원본, 번역, 생성 HTML을 함께 커밋합니다. 번역 원본·생성기·로컬 임시 파일은 `.assetsignore`로 공개 정적 자산에서 제외됩니다.

## 안면비대칭 칼럼 작성·생성

칼럼은 서버나 추가 패키지 없이 Python 3으로 정적 HTML을 생성합니다. 목록 주소는 `/columns`, 상세 주소는 `/columns/<slug>`이며, 각각 `columns.html`과 `columns/<slug>.html`을 배포합니다. 기존 안면비대칭 대표 안내는 `/asymmetry`에 유지합니다.

1. `content/columns/<slug>.json`에 `slug`, `title`, `description`, `published`, `modified`, `summary`, `image`, `imageAlt`를 작성합니다. 모든 값은 문자열이며 날짜는 실제 게시·수정일인 `YYYY-MM-DD`, 이미지 경로는 `/assets/...` 형태입니다. slug와 파일명은 동일한 영문 소문자·숫자·하이픈을 사용합니다.
2. 같은 이름의 `content/columns/<slug>.body.html`에 본문 조각을 작성합니다. 제목 H1·작성 기관·게시/수정일·페이지 틀은 생성기가 넣으므로 본문은 H2부터 사용합니다. 본문 이미지와 대체 텍스트, 참고 자료 링크도 이 파일에서 관리합니다. 이 폴더의 원고는 모두 공개 대상으로 생성되므로 미공개 초안은 별도로 보관합니다.
3. 저장소에서 `python -X utf8 scripts/build_columns.py`를 실행합니다. 목록·상세 HTML과 해당 사이트맵 항목을 함께 생성하며, 날짜를 오늘 날짜로 자동 변경하지 않습니다. 다른 사이트맵 URL과 수정일은 보존합니다.
4. `python -X utf8 scripts/build_columns.py --check`로 생성 결과가 원고 및 공통 틀과 일치하는지 확인합니다. 생성된 HTML을 직접 고치지 않고 원고를 수정한 뒤 다시 생성합니다.

공통 헤더·예약 UI·푸터와 기존 Meta 픽셀 코드는 `index.html`에서 가져옵니다. 공통 부분을 변경한 경우에도 다시 생성해야 합니다. 중첩 주소에서 자산과 메뉴가 정상 연결되도록 상대 URL을 루트 기준으로 바꾸며, 건강칼럼 진입점을 포함한 상단 메뉴도 `index.html`의 구성을 그대로 사용합니다. 칼럼 전용 스타일은 `columns.css`에서 관리합니다. 스타일 버전을 변경할 때는 생성기의 `STYLESHEET` 또는 `COLUMN_STYLESHEET` 값도 맞춥니다.
